## Commands

```bash
npm start          # Dev server with hot reload
npm run build      # Production build to build/
npm run serve      # Serve production build locally
npm run typecheck  # TypeScript type checking (tsc)
npm run clear      # Clear Docusaurus cache (.docusaurus/)
```

Node >= 20.0 required.

## Architecture

Docusaurus 3.9.2 site with React 19 and TypeScript. Uses the classic preset with autogenerated sidebars.

### Content Structure

Documentation lives in `docs/` with two independent sidebar sections:

- `docs/java/` — Java tutorials (basic-java, oop subcategories)
- `docs/ielts/` — IELTS English lessons (phase-1)

Each subcategory uses `_category_.json` for ordering. Sidebars are autogenerated from the filesystem in `sidebars.ts` — no manual sidebar entries needed.

### Adding a New Content Section

1. Create `docs/<topic>/` directory with markdown files
2. Add `_category_.json` in subdirectories for ordering
3. Add a new sidebar entry in `sidebars.ts`: `topicSidebar: [{type: 'autogenerated', dirName: '<topic>'}]`
4. Add navbar item in `docusaurus.config.ts` under `themeConfig.navbar.items`

### Key Config Files

- `docusaurus.config.ts` — Site config, navbar, theme, presets 
- `sidebars.ts` — Sidebar definitions (autogenerated from filesystem)
- `src/css/custom.css` — Infima theme color overrides
- `src/pages/index.tsx` — Homepage (currently minimal)
- `src/components/HomepageFeatures/` — Reusable feature cards component

### Docs Frontmatter

Markdown files use `sidebar_position` in frontmatter for ordering, and filenames are prefixed with numbers (e.g., `1_overview.md`, `2_jvm-jre-jdk.md`).

### Broken Links

`onBrokenLinks: 'throw'` is set — the build will fail on any broken internal links.
