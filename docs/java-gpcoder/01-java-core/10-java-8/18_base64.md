# Base64 encoding và decoding trong Java 8

## Base64 là gì?

**Base64** là một phương pháp mã hóa nhị phân-sang-văn-bản (binary-to-text encoding) chuyển đổi dữ liệu nhị phân (binary data) thành chuỗi ký tự ASCII. Tên "Base64" xuất phát từ việc sử dụng 64 ký tự in được (A-Z, a-z, 0-9, +, /) để biểu diễn dữ liệu.

**Mục đích sử dụng:**
- Nhúng dữ liệu nhị phân (hình ảnh, file) vào HTML/CSS/JSON.
- Truyền tải dữ liệu qua giao thức chỉ hỗ trợ văn bản (email, URL).
- Mã hóa thông tin xác thực (credentials) trong HTTP Basic Authentication.
- Lưu trữ khóa mật mã (cryptographic keys) dưới dạng chuỗi.

> **Lưu ý:** Base64 là **mã hóa** (encoding), KHÔNG phải **mã hóa bảo mật** (encryption). Bất kỳ ai cũng có thể giải mã (decode) Base64 — đừng dùng để bảo vệ dữ liệu nhạy cảm.

## Trước Java 8

Trước Java 8, Java không có lớp Base64 tích hợp sẵn. Lập trình viên phải dùng thư viện bên ngoài (`Apache Commons Codec`, `Guava`) hoặc lớp nội bộ không chính thức `sun.misc.BASE64Encoder` (không nên dùng vì không ổn định).

## java.util.Base64 trong Java 8

Java 8 tích hợp lớp `java.util.Base64` với ba loại encoder/decoder:

| Loại | Bộ ký tự | Dùng khi |
|---|---|---|
| **Basic** | A-Z, a-z, 0-9, +, / (với padding `=`) | Mặc định, dùng chung |
| **URL** | A-Z, a-z, 0-9, -, _ (thay + và /) | Nhúng vào URL/tên file |
| **MIME** | Giống Basic nhưng xuống dòng sau 76 ký tự | Email MIME |

## Basic Encoding/Decoding

```java
import java.util.Base64;

public class Demo {
    public static void main(String[] args) {
        String vanBanGoc = "Xin chào Java 8! Tiếng Việt OK.";

        // --- ENCODING (Mã hóa) ---
        // getEncoder() trả về Base64.Encoder
        Base64.Encoder encoder = Base64.getEncoder();
        byte[] encodedBytes = encoder.encode(vanBanGoc.getBytes());
        String encodedStr = encoder.encodeToString(vanBanGoc.getBytes());

        System.out.println("Gốc:    " + vanBanGoc);
        System.out.println("Mã hóa: " + encodedStr);
        // Mã hóa: WGluIGNow6BvIEphdmEgOCEgVGnhur9uZyBWaeG7h3QgT0su

        // --- DECODING (Giải mã) ---
        Base64.Decoder decoder = Base64.getDecoder();
        byte[] decodedBytes = decoder.decode(encodedStr);
        String decodedStr = new String(decodedBytes);

        System.out.println("Giải mã: " + decodedStr);
        // Giải mã: Xin chào Java 8! Tiếng Việt OK.

        System.out.println("Khớp: " + vanBanGoc.equals(decodedStr)); // true
    }
}
```

## URL-safe Encoding

Ký tự `+` và `/` trong Base64 Basic có thể gây vấn đề khi nhúng vào URL. Base64 URL thay `+` bằng `-` và `/` bằng `_`.

```java
// Dữ liệu tạo ra ký tự + hoặc / trong Base64 Basic
byte[] duLieu = {(byte)0xFB, (byte)0xFC, (byte)0xFD};

String basic = Base64.getEncoder().encodeToString(duLieu);
String url = Base64.getUrlEncoder().encodeToString(duLieu);

System.out.println("Basic: " + basic); // +/z9 (có ký tự +, /)
System.out.println("URL:   " + url);   // -_z9 (thay bằng -, _)

// Giải mã URL-safe
byte[] restored = Base64.getUrlDecoder().decode(url);
```

## MIME Encoding (Dùng cho Email)

MIME (Multipurpose Internet Mail Extensions) encoding ngắt dòng sau mỗi 76 ký tự với `\r\n` — phù hợp với chuẩn email.

```java
// Tạo dữ liệu dài để thấy rõ ngắt dòng
byte[] duLieuDai = new byte[100];
new java.util.Random().nextBytes(duLieuDai);

String mime = Base64.getMimeEncoder().encodeToString(duLieuDai);
System.out.println("MIME Base64:");
System.out.println(mime);
// Kết quả xuống dòng sau 76 ký tự:
// xG3K7mNp2QvT8wLhYfPaRdIs0bUcXjZo5nVqe1MkHgCuAyOWEB4tFr9DSiJlN6v
// 3phmwTXdLqYZkRsMuNcbJeKo0vQg8i1PfxBt2AyECrHGlW7Oa4VnUF5sjDzIO9X
// ...

// Tùy chỉnh độ dài dòng và ký tự ngắt dòng
Base64.Encoder customMime = Base64.getMimeEncoder(60, new byte[]{'\n'});
```

## Mã hóa hình ảnh sang Base64

Ứng dụng phổ biến: nhúng hình ảnh trực tiếp vào HTML/CSS.

```java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Base64;

public class HinhAnhBase64 {
    public static String hinhAnhSangBase64(String duongDanFile) throws IOException {
        byte[] duLieuHinh = Files.readAllBytes(Path.of(duongDanFile));
        return Base64.getEncoder().encodeToString(duLieuHinh);
    }

    public static void luuHinhAnhTuBase64(String base64, String duongDanLuu)
            throws IOException {
        byte[] duLieu = Base64.getDecoder().decode(base64);
        Files.write(Path.of(duongDanLuu), duLieu);
    }

    public static String taoDataUri(String base64, String loaiFile) {
        // Data URI dùng nhúng hình vào HTML: <img src="data:image/png;base64,...">
        return "data:image/" + loaiFile + ";base64," + base64;
    }
}
```

## Mã hóa thông tin xác thực HTTP Basic Auth

HTTP Basic Authentication (xác thực cơ bản HTTP) mã hóa `username:password` bằng Base64 và đặt vào HTTP header.

```java
import java.util.Base64;

public class BasicAuth {
    public static String taoHeader(String username, String matKhau) {
        String thongTin = username + ":" + matKhau;
        String encoded = Base64.getEncoder()
            .encodeToString(thongTin.getBytes());
        return "Basic " + encoded;
    }

    public static String[] giaima(String headerValue) {
        // Bỏ "Basic " ở đầu
        String encoded = headerValue.substring(6);
        String decoded = new String(Base64.getDecoder().decode(encoded));
        return decoded.split(":", 2); // ["username", "password"]
    }

    public static void main(String[] args) {
        String header = taoHeader("admin", "matkhau123");
        System.out.println("Authorization: " + header);
        // Authorization: Basic YWRtaW46bWF0a2hhdTEyMw==

        String[] thongTin = giaima(header.substring("Authorization: ".length()));
        System.out.println("Username: " + thongTin[0]); // admin
        System.out.println("Mật khẩu: " + thongTin[1]); // matkhau123
    }
}
```

## Encoding không có padding

Padding là ký tự `=` thêm vào cuối để đảm bảo độ dài chia hết cho 4. Đôi khi cần bỏ padding:

```java
String vanBan = "Java8";

// Mặc định có padding
String voPadding = Base64.getEncoder().withoutPadding()
    .encodeToString(vanBan.getBytes());
String coPadding = Base64.getEncoder()
    .encodeToString(vanBan.getBytes());

System.out.println("Có padding:  " + coPadding);   // SmF2YTg=
System.out.println("Không padding: " + voPadding); // SmF2YTg

// Decoder vẫn giải mã được cả hai
byte[] restored = Base64.getDecoder().decode(voPadding);
System.out.println(new String(restored)); // Java8
```

## Tóm tắt

| Phương thức | Mô tả |
|---|---|
| `Base64.getEncoder()` | Basic encoder (có padding `=`) |
| `Base64.getDecoder()` | Basic decoder |
| `Base64.getUrlEncoder()` | URL-safe encoder (dùng `-` và `_`) |
| `Base64.getUrlDecoder()` | URL-safe decoder |
| `Base64.getMimeEncoder()` | MIME encoder (xuống dòng sau 76 ký tự) |
| `Base64.getMimeDecoder()` | MIME decoder |
| `encoder.withoutPadding()` | Encoder không có ký tự `=` cuối |
| `encoder.encodeToString(bytes)` | Mã hóa bytes thành String |
| `decoder.decode(String)` | Giải mã String thành bytes |
