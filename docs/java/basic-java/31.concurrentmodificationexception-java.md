# Tranh ConcurrentModificationException trong Java

## ConcurrentModificationException la gi?

**ConcurrentModificationException (CME)** la mot loi runtime xay ra khi ban **thay doi cau truc cua collection** (them, xoa phan tu) trong khi dang **duyet (iterate)** qua no. Day la mot trong nhung loi pho bien nhat khi lam viec voi `List`, `Set`, va `Map` trong Java.

Hay tuong tuong ban dang **doc danh sach hoc sinh** trong lop (iterate), dong thoi ban khac dang **xoa ten hoc sinh** khoi danh sach (modify). Khi ban doc den ten da bi xoa, moi thu tro nen hon loan -- do chinh la `ConcurrentModificationException`.

Luu y: Ten la "Concurrent" nhung loi nay **khong chi xay ra trong multi-thread**. No hoan toan co the xay ra trong **cung mot thread** neu ban modify collection trong khi dang for-each.

---

## 1. Demo loi: Remove trong for-each

```java
import java.util.ArrayList;
import java.util.List;

public class CmeDemo {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");
        fruits.add("Date");

        // ❌ Loi: Remove trong for-each
        try {
            for (String fruit : fruits) {
                if (fruit.startsWith("B")) {
                    fruits.remove(fruit); // ConcurrentModificationException!
                }
            }
        } catch (java.util.ConcurrentModificationException e) {
            System.out.println("Loi: " + e.getClass().getSimpleName());
        }
    }
}
```

**Tai sao loi?** Vong for-each su dung `Iterator` phia sau. Khi ban goi `fruits.remove()` truc tiep (khong qua Iterator), Iterator phat hien collection da bi thay doi va throw `ConcurrentModificationException`.

---

## 2. Nguyen nhan chi tiet: Fail-fast Iterator

Java su dung co che **fail-fast** cho Iterator cua cac collection nhu `ArrayList`, `HashMap`, `HashSet`:

```java
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class FailFastDemo {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>(List.of(1, 2, 3, 4, 5));

        // ❌ Loi: Goi collection.remove() trong khi dang iterate
        try {
            Iterator<Integer> it = numbers.iterator();
            while (it.hasNext()) {
                Integer num = it.next();
                if (num == 3) {
                    numbers.remove(num); // Goi tren COLLECTION, khong phai Iterator
                    // -> ConcurrentModificationException
                }
            }
        } catch (java.util.ConcurrentModificationException e) {
            System.out.println("Fail-fast: " + e.getClass().getSimpleName());
        }
    }
}
```

**Co che hoat dong:**
- Iterator giu mot bien `expectedModCount` = `modCount` cua collection.
- Moi khi `add()` hoac `remove()` tren collection, `modCount` tang len.
- Khi `iterator.next()` duoc goi, no kiem tra `modCount != expectedModCount` -> throw CME.
- Chi co `Iterator.remove()` moi dong bo duoc `expectedModCount` voi `modCount`.

## 3. Cach khac phuc (4 cach)

### Cach 1: Dung Iterator.remove()

```java
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class FixWithIterator {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");
        fruits.add("Date");

        // ✅ Dung: Su dung Iterator.remove()
        Iterator<String> it = fruits.iterator();
        while (it.hasNext()) {
            String fruit = it.next();
            if (fruit.startsWith("B")) {
                it.remove(); // An toan! Iterator tu dong dong bo modCount
            }
        }

        System.out.println(fruits); // [Apple, Cherry, Date]
    }
}
```

**Uu diem:** Don gian, hoat dong voi moi phien ban Java.
**Nhuoc diem:** Chi ho tro `remove()`, khong ho tro `add()`.

### Cach 2: Dung removeIf() (Java 8+)

```java
import java.util.ArrayList;
import java.util.List;

public class FixWithRemoveIf {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");
        fruits.add("Blueberry");

        // ✅ Dung: removeIf (Java 8+) -- gon nhat
        fruits.removeIf(fruit -> fruit.startsWith("B"));

        System.out.println(fruits); // [Apple, Cherry]
    }
}
```

**Uu diem:** Gon gang, doc hieu de dang, an toan.
**Nhuoc diem:** Chi ho tro **xoa** theo dieu kien, khong ho tro them hay sua.

### Cach 3: Copy collection roi modify

```java
import java.util.ArrayList;
import java.util.List;

public class FixWithCopy {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");

        // ✅ Dung: Duyet ban copy, modify ban goc
        List<String> toRemove = new ArrayList<>();

        for (String fruit : fruits) {
            if (fruit.startsWith("B")) {
                toRemove.add(fruit); // Ghi nho phan tu can xoa
            }
        }

        fruits.removeAll(toRemove); // Xoa sau khi duyet xong

        System.out.println(fruits); // [Apple, Cherry]
    }
}
```

**Hoac duyet ban copy:**

```java
import java.util.ArrayList;
import java.util.List;

public class FixWithCopy2 {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");

        // ✅ Duyet ban copy (new ArrayList), modify ban goc
        for (String fruit : new ArrayList<>(fruits)) {
            if (fruit.startsWith("B")) {
                fruits.remove(fruit); // An toan vi dang duyet ban copy
            }
        }

        System.out.println(fruits); // [Apple, Cherry]
    }
}
```

**Uu diem:** Linh hoat, co the them/xoa/sua tu do.
**Nhuoc diem:** Ton them bo nho do tao ban copy.

### Cach 4: Dung CopyOnWriteArrayList (thread-safe)

```java
import java.util.List;
import java.util.concurrent.CopyOnWriteArrayList;

public class FixWithCOWList {
    public static void main(String[] args) {
        List<String> fruits = new CopyOnWriteArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");

        // ✅ An toan: CopyOnWriteArrayList khong throw CME
        for (String fruit : fruits) {
            if (fruit.startsWith("B")) {
                fruits.remove(fruit); // Khong loi!
            }
        }

        System.out.println(fruits); // [Apple, Cherry]
    }
}
```

**Uu diem:** Thread-safe, khong bao gio throw CME.
**Nhuoc diem:** Moi lan `add()`/`remove()` deu **copy toan bo mang**, rat cham voi collection lon hoac ghi nhieu.

## 4. Fail-fast vs Fail-safe Iterator

```java
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CopyOnWriteArrayList;
import java.util.Iterator;

public class FailFastVsFailSafe {
    public static void main(String[] args) {
        // === Fail-fast: ArrayList, HashMap, HashSet... ===
        List<String> failFast = new ArrayList<>(List.of("A", "B", "C"));
        try {
            for (String s : failFast) {
                failFast.add("D"); // ConcurrentModificationException!
            }
        } catch (java.util.ConcurrentModificationException e) {
            System.out.println("Fail-fast: Loi ngay khi modify!");
        }

        // === Fail-safe: CopyOnWriteArrayList, ConcurrentHashMap... ===
        List<String> failSafe = new CopyOnWriteArrayList<>(List.of("A", "B", "C"));
        for (String s : failSafe) {
            failSafe.add("D"); // Khong loi!
        }
        System.out.println("Fail-safe: " + failSafe);
        // [A, B, C, D, D, D] -- Iterator duyet ban snapshot cu
    }
}
```

**So sanh:**

| Dac diem | Fail-fast | Fail-safe |
|----------|-----------|-----------|
| **Throw CME** | Co | Khong |
| **Iterate tren** | Collection goc | Ban copy (snapshot) |
| **Bo nho** | It | Nhieu (do copy) |
| **Vi du** | ArrayList, HashMap, HashSet | CopyOnWriteArrayList, ConcurrentHashMap |
| **Su dung** | Single-thread | Multi-thread |

---

## Khi nao dung?

| Tinh huong | Giai phap khuyen dung |
|------------|----------------------|
| Xoa phan tu khi iterate (single-thread) | `Iterator.remove()` hoac `removeIf()` |
| Xoa nhieu phan tu theo dieu kien | `removeIf()` (Java 8+) |
| Can them phan tu khi iterate | Copy collection roi modify |
| Multi-thread truy cap collection | `CopyOnWriteArrayList`, `ConcurrentHashMap` |
| Doc nhieu, ghi it (multi-thread) | `CopyOnWriteArrayList` |
| Doc it, ghi nhieu (multi-thread) | `Collections.synchronizedList()` + synchronized block |

**Best practices:**
- **Mac dinh dung `removeIf()`** (Java 8+) -- gon nhat va an toan.
- Dung `Iterator.remove()` khi can kiem soat logic phuc tap hon.
- Chi dung `CopyOnWriteArrayList` khi **that su can** thread-safety va **doc nhieu hon ghi**.
- Khong bao gio goi `collection.remove()` truc tiep trong for-each.

## Loi thuong gap

### Loi 1: Xoa phan tu truc tiep trong for-each

```java
// ❌ Sai: Goi remove() tren collection trong for-each
for (String item : list) {
    if (item.equals("delete-me")) {
        list.remove(item); // ConcurrentModificationException!
    }
}
```

```java
// ✅ Dung: Dung removeIf()
list.removeIf(item -> item.equals("delete-me"));
```

### Loi 2: Nham lan Iterator.remove() va Collection.remove()

```java
// ❌ Sai: Dung collection.remove() thay vi iterator.remove()
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String item = it.next();
    list.remove(item);  // Goi tren COLLECTION -> CME!
}
```

```java
// ✅ Dung: Dung it.remove() (goi tren ITERATOR)
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String item = it.next();
    if (shouldRemove(item)) {
        it.remove();  // Goi tren ITERATOR -> An toan!
    }
}
```

### Loi 3: Tuong rang CopyOnWriteArrayList giai quyet moi van de

```java
// ❌ Sai: Dung COWAL cho collection lon, ghi nhieu
// Moi lan add/remove deu copy TOAN BO mang -> cuc ky cham!
List<String> bigList = new CopyOnWriteArrayList<>();
for (int i = 0; i < 100_000; i++) {
    bigList.add("item-" + i);  // Moi lan add = copy 100K phan tu!
}
```

```java
// ✅ Dung: COWAL chi phu hop khi doc nhieu, ghi it
// Voi collection lon + ghi nhieu, dung synchronized hoac ConcurrentLinkedQueue
```

### Loi 4: Them phan tu trong for-each

```java
// ❌ Sai: Them phan tu cung gay CME
for (String item : list) {
    if (item.equals("special")) {
        list.add("new-item"); // ConcurrentModificationException!
    }
}
```

```java
// ✅ Dung: Ghi nho roi them sau
List<String> toAdd = new ArrayList<>();
for (String item : list) {
    if (item.equals("special")) {
        toAdd.add("new-item");
    }
}
list.addAll(toAdd); // Them sau khi duyet xong
```

## Cau hoi phong van

### Cau 1: Tai sao for-each throw ConcurrentModificationException?

**Tra loi:** Vong for-each trong Java duoc compiler chuyen thanh code su dung `Iterator`. Iterator cua cac collection chuan (ArrayList, HashMap...) su dung co che **fail-fast**: no luu gia tri `expectedModCount` tai thoi diem tao Iterator. Moi khi goi `next()`, Iterator kiem tra xem `modCount` cua collection co bang `expectedModCount` khong. Neu collection bi modify (add/remove) truc tiep (khong qua Iterator), `modCount` thay doi nhung `expectedModCount` khong cap nhat -> Iterator phat hien va throw CME.

### Cau 2: Iterator.remove() khac gi Collection.remove()?

**Tra loi:**
- **Iterator.remove()**: Xoa phan tu vua duoc tra ve boi `next()`. Sau khi xoa, no **cap nhat `expectedModCount`** de dong bo voi `modCount` cua collection. Do do khong gay CME.
- **Collection.remove()**: Xoa truc tiep tren collection. Chi tang `modCount` ma **khong cap nhat `expectedModCount`** cua Iterator dang chay. Khi Iterator goi `next()`, no phat hien `modCount != expectedModCount` va throw CME.

### Cau 3: CopyOnWriteArrayList hoat dong nhu the nao?

**Tra loi:** `CopyOnWriteArrayList` luu tru du lieu trong mot mang internal. Moi khi co thao tac **ghi** (add, set, remove), no:
1. Tao mot **ban copy moi** cua toan bo mang.
2. Thuc hien thay doi tren ban copy.
3. Cap nhat reference sang mang moi.

Iterator duoc tao se duyet tren **snapshot** (ban sao tai thoi diem tao Iterator), nen khong bi anh huong boi cac thay doi sau do -> khong bao gio throw CME.

**Trade-off:** An toan voi concurrent, nhung **cham khi ghi** (vi phai copy toan bo mang). Phu hop khi **doc nhieu, ghi it**.

### Cau 4: Fail-fast la gi? Khac gi fail-safe?

**Tra loi:**
- **Fail-fast**: Iterator phat hien thay doi tren collection va **throw CME ngay lap tuc**. Muc dich la bao loi som de tranh ket qua khong chinh xac. Vi du: `ArrayList.iterator()`, `HashMap.keySet().iterator()`.
- **Fail-safe**: Iterator lam viec tren **ban copy** cua collection, nen khong phat hien thay doi va **khong bao gio throw CME**. Vi du: `CopyOnWriteArrayList.iterator()`, `ConcurrentHashMap.keySet().iterator()`.

**Luu y:** "Fail-safe" khong phai thuat ngu chinh thuc trong Java spec. Java chi dinh nghia "fail-fast". Cac collection trong `java.util.concurrent` duoc goi la **weakly consistent** (nhat quan yeu).
