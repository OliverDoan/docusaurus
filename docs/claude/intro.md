# Dùng Claude hiệu quả

Đây là hướng dẫn **cách dùng Claude hiệu quả** — từ trò chuyện cơ bản trên web, viết prompt (câu lệnh yêu cầu) cho tới dùng **Claude Code** để lập trình. Tài liệu dành cho người mới, mỗi **thuật ngữ chuyên ngành** (technical term — từ ngữ kỹ thuật riêng của ngành) đều được giải thích ngay khi xuất hiện lần đầu.

---

## Claude là gì?

**Claude** là trợ lý AI (trí tuệ nhân tạo) do công ty **Anthropic** phát triển. Bạn có thể trò chuyện với Claude bằng ngôn ngữ tự nhiên (tiếng Việt, tiếng Anh...) để:

- Viết và chỉnh sửa văn bản, email, tài liệu
- Lập trình: viết code, sửa lỗi, giải thích code
- Học tập: giải thích khái niệm, tóm tắt, dịch thuật
- Phân tích dữ liệu, file PDF, hình ảnh
- Brainstorm (động não) ý tưởng, lập kế hoạch

> **AI** (Artificial Intelligence — trí tuệ nhân tạo): công nghệ giúp máy tính "hiểu" và tạo ra ngôn ngữ giống con người. Claude thuộc nhóm **LLM** (Large Language Model — mô hình ngôn ngữ lớn), được huấn luyện trên lượng văn bản khổng lồ.

---

## Có những cách nào dùng Claude?

| Cách dùng | Dành cho | Mô tả |
|-----------|----------|-------|
| **claude.ai** (web/app) | Mọi người | Giao diện chat, dễ dùng nhất |
| **Claude Code** (CLI) | Lập trình viên | Công cụ dòng lệnh để code ngay trong terminal |
| **API** | Developer xây ứng dụng | Tích hợp Claude vào phần mềm của bạn |

> **CLI** (Command-Line Interface — giao diện dòng lệnh): cách điều khiển máy tính bằng cách gõ lệnh trong cửa sổ terminal, thay vì bấm chuột.

## Nguyên tắc vàng khi dùng Claude

1. **Càng rõ ràng, kết quả càng tốt** — nói cụ thể bạn muốn gì, định dạng ra sao.
2. **Cung cấp đủ bối cảnh** (context) — Claude không biết thông tin bạn chưa nói.
3. **Lặp lại và tinh chỉnh** — nếu chưa ưng, hãy yêu cầu sửa thay vì làm lại từ đầu.
4. **Luôn kiểm chứng** — Claude có thể sai (gọi là *hallucination* — bịa thông tin), nhất là số liệu và sự kiện.

Bắt đầu từ chủ đề **1. Bắt đầu với Claude** ở thanh bên trái.
